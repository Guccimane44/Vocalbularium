Explique un terme, une expression ou une phrase tels que les mathématiques les comprennent, en quelques mots simples dans la langue dans laquelle vous utilisez Vocabularium, souvent avec un petit exemple.

Utilisez-le pour les mots et les énoncés mathématiques, comme *valeur propre*, *anneau* ou *corps*. Une clé dans une autre langue est tout de même expliquée dans la vôtre.
