## Automated verification

Local macOS, PostgreSQL 18, Playwright Chromium (headless), with controlled generation providers and disposable databases. No live model calls, and not the owner's running account. Source revision `2d3044c`.

- `npm run check`: passed (types, theme drift, syntax).
- `npm test`: 152/152. Includes the parent catalog, facet rules and render contract (`parents.test.mjs`), facets in storage and the waiting facets (`facets.test.mjs`), parent generation (`components.test.mjs`, `generation.test.mjs`), the `0010` and `0011` upgrades (`upgrade.test.mjs`), and the Translation colours in both themes (`contrast.test.mjs`).
- Browser: 25/25 (`app.browser.test.mjs`, `logging.browser.test.mjs`) against a build of the same source pointed at a test API on port 4328, because the owner's API held port 4318. The browser suite was **not** run against the extracted candidate, whose only difference is the API address it was built for.
- CI on `main` after #143 ([run 38638181557](https://github.com/Guccimane44/Vocalbularium/actions/runs/38638181557)): passed.

## Live generation sample

The golden set (`tests/golden/parents.json`, 24 inputs through both parents) ran against OpenCode Go with `deepseek-v4.1-flash` on 14 October 2026, before increment 3 merged:

- First run: 34 of 48 outputs; 12 Chinese outputs broke the render contract with `[n]` or a part of speech in place of meaning numbers, and two German calls were cut off or timed out.
- After the prompt fix (real meaning numbers, Pinyin per meaning, 8,192 output tokens): 46 of 48. One provider returned invalid JSON; one empty Article heading is now dropped as an omitted facet.

The review files stay in the ignored `.data/golden/`. This is a sample for the owner's review, not an automated quality gate.
