## Automated verification

Local macOS, PostgreSQL 18, Playwright Chromium (headless), with controlled generation providers and disposable databases. No live model calls, and not the owner's running account.

- `npm run check`: passed (types, theme drift, syntax).
- `npm test`: 131 tests; 129 passed in the full run. The 2 failures were the local PostgreSQL `permission denied to terminate process` race in test cleanup (being fixed separately); both passed on rerun. The suite includes:
  - unit tests for module families, the meaning line, the renderer (recorded formats and ten fallback cases);
  - `tests/contrast.test.mjs`: every token pair the interface draws, in both themes.
- `npm run test:browser`: 23/23 on the source build.
- 23/23 against the **extracted candidate** (`VOCABULARIUM_TEST_EXTENSION`).

## Not verified

- **Owner checks:** installation and acceptance; how the motion feels (only its presence and reduced-motion behaviour are tested); the API and extension upgrade on the owner's own account.
- **CJK fonts on other systems:** system serif fonts on Windows and Linux. The screenshots are macOS only.
- **Live generation:** content from a live provider in the renderer. Recorded formats are covered; real output may vary and then falls back to plain text.
