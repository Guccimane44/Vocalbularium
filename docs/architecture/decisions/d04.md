## Decision

Per-card page actions and drag-only shaping: each card has **Edit** (one card at a time, Save and Cancel in the card), **Generate** (first run, no warning) or **Retry**, and **Delete**; the main key card has only Edit; no page-level Edit page, Generate missing or Retry page; Delete page moves to the header. No Add buttons in the module window and no ↑/↓ move buttons on pages or in deck settings; keyboard users drag window modules and card handles with Space and the arrow keys. Module labels lose their angle brackets. Fixes the reorder flicker and unreliable window drags
