## Decision

Page-owned modules: the deck configuration is only the template for page creation. Afterwards the user deletes any component except the main key (immediately, after a warning; a deleted component stays gone), rearranges components, and drags modules onto one page from a module window shown beside the page view and deck settings. Deck changes affect only new pages. The main key and Context become input modules: the main key is compulsory and always first, the Context is optional (at most one, movable) and replaces the Capture with Context setting, and the limit of 12 module instances per deck or page includes both. A module dragged onto a page waits as "Not generated yet". Amends Q72's live configuration (C15) and Q07's deck setting (C16); settles K15–K18. *Amended 10 October 2026:* the user's own text becomes a repeatable Text input module that counts toward the 12 and replaces manual components; the 0.5.0 upgrade discards existing decks and pages and keeps sign-in ([plan](../../history/plans/page-owned-modules.md))
