## Decision

**One text request per module; no request is shared by all modules.** The run's word-or-sentence interpretation is removed. Each content module writes its card in one request: the core with its **flags** first (Languages: `kind`, `language`, and for German `gramRole`; Expertise: `relevance`, D16's three cases; Mathematics `formula`, Computer Science `code`), then every text facet, each applying by its own prompt and checked against the flags afterwards. No gate and no core-then-facets split: the experiment found both no better than one request, and the split slower. The Languages word and sentence prompts merge into one core shape; German's grammar facets describe one grammar word. The classification moves from under the main key into each Languages core header, in the module's language, not editable. **New facets:** German Conjugation, Declension, Comparison and Case; Mathematics Formula; Computer Science Code example (subject keys only), with tables, KaTeX and highlighted code. **Every generation is unique**, never cached. Heavy facets (audio, images) are recorded as a direction: separate parallel jobs after the text. **Upgrade:** every deck and page is discarded; accounts, sign-in and the language preference stay, with a fresh My Deck.
