## Decision

**The family heading opens its page; native language names; Expertise samples in the interface language; a Python facet.** In the module window the family's mark and name in a group's heading open the family's page and the rest of the heading folds the group, in place of the link at the top of the group (amends D20). The pages' language dropdown names each language in itself only (*Français*, not *Français · French*; amends K64). The Expertise samples use *quadratic equation* (Mathematics), written in the interface language (一元二次方程 in Chinese), with the sentence *A quadratic equation has at most two real solutions.*, and *Hello, world* (Computer Science), kept in English in every language, with the sentence *Every programmer's first program prints “Hello, world”.*, in place of *eigenvalue* and *Frontend* (amends D20). Computer Science's Code example (Cd) becomes **Python** (Py): one short, commented Python example, under the same flag `hasCode`; its facet ID stays `code`, so existing cards keep theirs (amends D17). A facet page's sample sits on its card, the core and the card's other facets dimmed and the facet highlighted in full, in place of a separate **Where it sits**; the card is the facet's own sample's when it has one, so Conjugation's core is *sprechen*; the flow from the key to the core above the card goes (amends D20). Every facet page has at least one representative sample: Synonyms and Antonyms, which *language* has none of, use *good* (*gut*), and Declension adds *good* as an adjective beside the noun *language*, its samples chosen as **Noun**, **Adjective** or **Sentence** (amends K65). Only the Languages module pages keep their facts: the Expertise pages lose *Reads*, *Writes* and *Best for* and what each facet applies to, and the Text and Context pages their facts and **For example** (amends D20). No migration.
