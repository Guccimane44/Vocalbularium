## Decision

**English first, localised for 1.0.** Every interface text in Vocabularium is English, and during development English is the default **language preference**. The interface will be localised into the major languages, which the user chooses as a preference, and 1.0 ships with them; English stays the default. The interface language is independent of the language of generated content, which stays multilingual by module ([Q69](../questionnaire/13-ux-and-migration.md#q69-which-languages-does-the-ui-speak)). Recorded now so that new interface text, D13's explanations and the Expertise modules' English ([modules](../../specs/modules.md#catalog)) are understood as the English default, not a permanent choice; the languages, the preference and the string process are planned in a later release before 1.0. Answers Q69's open point (K10): English-only is a development position, not the 1.0 one
