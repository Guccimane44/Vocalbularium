## Decision

A deck's colour becomes a setting: deck settings offer the six family colours as swatches named by hue, a new deck starts with one at random, and a deck never coloured keeps the colour derived from its ID, so upgrading changes nothing (amends D05's derived, setting-free deck colour). An empty component, including Text the user has not filled and a content module not generated yet, shows only its index tab, with its actions on hover and focus and no placeholder line such as "+ Text — add your own notes" or "Not generated yet"; the deck-settings preview follows the same rule
