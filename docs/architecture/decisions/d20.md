## Decision

**Family, module and facet pages in one sheet, with samples a user can choose.** The explanations of D13 become pages in a side sheet over the module window, linked by a path at the top (*Languages / German / Article*); the module dialog, the explanation that expands in the facet window and D18's facet About dialog are removed. A **family page** opens from the family's heading in the module window; a **module page** from **About German** below the module (a text link replacing D18's ⓘ), from a card's new **About German** and from deck settings; a **facet page** from a facet-window row's **›** and a facet's About on a card. The pages are static, the same wherever they open: no add button and nothing from the current card. A module page has a header, three facts, **How it looks** (a sample whose key language is chosen from a dropdown of the interface languages and Word or Sentence, the key set above a card that shows the core and a hint that facets follow), **How it works** (four lines: main key, read as, module core, facets) and its facets with what they apply to. A facet page has Applies to (only what applies), Describes, samples, where it sits and the module's other facets. The pages say *core*, not *grammar word*. The Languages modules' samples are *language* and *Languages are the bridges connecting people and the world.* in each interface language; a facet that never applies to a noun uses a word beside it (Conjugation: *speak*); the Expertise modules keep their subject's own term; the 幸福 sample is retired. No stored data changes. Detail: [D20](../d20-module-pages.md); reference design: the owner's settled canvas, its source in [d20-design](../d20-design/).
