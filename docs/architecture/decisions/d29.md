# D29: a Languages core gives the context meaning first and the original meaning always

Full entry of the [traceability map](../traceability-map.md#entries).

- **Opened:** 2026-11-05
- **Source:** the owner's request in a Claude Code chat, 5 November 2026, with the *breadcrumb* card in the fourth deck as the example: the core "should indicate the context specific meaning when applicable. the original meaning of the main key should always be given", the context meaning first, under "(in diesem Zusammenhang)". ## Context

A Languages core lists the key's meanings. When the Context selects one sense, the model can give only that sense. The *breadcrumb* card (Context "breadcrumb ui") reads only "Navigationspfad in einer Benutzeroberfläche, der die Position innerhalb einer Website anzeigt". A learner never sees the word's own meaning, a crumb of bread, and cannot tell which line is the sense used here.

## Decision

- **A new optional field.** A Languages core (German, Chinese) gains `contextual`, the key's meaning in this Context, beside `meanings`. `meanings` lists the key's own senses and always includes its original meaning.
- **Shown first, under the module's label.** The formatter writes the context meaning as the first numbered line, under a label the module owns, like its header labels: German `(in diesem Zusammenhang)`, Chinese `（在此语境中）`. The model never writes the label.

  > 1. (in diesem Zusammenhang) Navigationspfad in einer Benutzeroberfläche, der die Position innerhalb einer Website anzeigt
  > 2. Brotkrümel; kleines Stück Brot

- **When it applies:**
  - **Words and phrases only.** A sentence's translation already follows its Context.
  - **When the Context narrows the sense.** With no Context, or one that doesn't narrow it, there's no `contextual` and the core reads as before.
  - **No duplicate.** When the Context selects the ordinary sense, that sense is the labelled line and isn't repeated in `meanings`.
- **A key with several readings** (a Chinese 多音字 such as 行, háng or xíng) keeps to the reading the Context uses: its original meaning is that reading's literal or most common sense, and senses of the other reading are not added (owner, 5 November 2026: "staying within the reading the context uses").
- **The grammar word** (`gramRole` and the grammar facets) follows the first line, the context meaning.
- **Pronunciation never speaks the label.**
- **Reading it back:** the core's `read` turns a stored first line that starts with the label back into `contextual`. So a facet's Retry, the core's Retry (D28), the core's Edit and `providerCore` keep it. A line whose label the user deleted is an ordinary meaning.
- **A check** (`checks`): the label appears at most once, and only on the first line.

The stored form is unchanged: markdown, one meaning per line. No migration. Existing cards show the context meaning only after a Retry. The Expertise modules are out of scope.

## Alternatives considered

- Ask for the label in the prompt alone. The model can forget it, word it differently or put it on the wrong line, and `read` could not tell it apart reliably.
- Mark one of `meanings` as contextual by index. That's harder to read back from stored markdown, and an edit that reorders lines breaks it.

## Consequences

- The core's shape changes for German and Chinese. Their prompts, prompt fixtures, rubrics and golden sets change with it.
- A new Languages module gets the same field and its own label in its own folder (D25: nothing shared between modules).

## Evidence

0.16.3:

- **Offline:** `tests/content.test.mjs` (`format` and `read` round-trip with and without `contextual`; an edit that deletes the label becomes an ordinary meaning), `tests/content-checks.test.mjs` (the `context-meaning` and Pronunciation `no-context-label` checks), `tests/opencode.test.mjs` (the schema's field order), and the prompt fixtures.
- **Live golden set** (`npm run gate -- german`, `npm run gate -- chinese`, 5–6 November 2026, runs 3 and 4). Every D29 case got the right meanings in both modules at least once: *bank* by a river and *bank* before closing time, *breadcrumb* / "ui", *Schloss* at a front door, *行* in a line of work (the háng reading only), *refrigerator* with a Context that does not narrow it (no context meaning), and *Fernweh* with no Context (no context meaning). No card had an unexpected `contextual` flag or failed a content check in run 4.
- **The gate did not pass.** The failures were provider timeouts (4 German, 5 Chinese in run 4), cores with fields the shape does not name (German `facets`, which also occurred before D29; Chinese 行 `contextual_note`, likely prompted by the new field), and faults outside the meanings (a German conjugation and an article, Chinese pinyin, and 4 Chinese cards the judge scored weak). The owner accepted D29 on this evidence on 6 November 2026 ("Record and open PR"). The invented fields are a follow-up of their own.
- **Not yet run:** the browser smoke check that regenerates the owner's *breadcrumb* card.
