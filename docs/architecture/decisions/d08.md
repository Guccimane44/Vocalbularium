## Decision

Content modules become **parent modules** with a required **core** and optional **facets**, so the word/phrase and sentence modalities change how a module works instead of which modules apply. The run's interpretation only decides word/phrase or sentence, shown under the main key and not correctable; it no longer chooses a source language, which each parent's generation reads from the key. The core always applies: a word or phrase gets an explanation in the parent's language in today's *German explanation* style, a sentence gets a translation, and a key already in the parent's language is explained in that language, its translation being the key itself. Facets describe the translation and are shown in an order the parent type defines; a facet that does not apply to the input is not shown. A parent is added with its core only. Facets are listed in the module window beneath their parent and added like modules, by dragging or **+**, but only to a parent of their own type, on a page or in deck settings; an added facet waits until Retry regenerates the whole parent, and a facet is deleted like a component. Parent and facets are one component, from one generation; Retry regenerates the whole parent. Several parents of one type on a page generate independently. Variety comes from more parent types, not options. First catalog, family **Translation**: **German** (facets Article, Examples, Synonyms, Antonyms) and **Chinese** (facets Examples, Pinyin; simplified characters); on a sentence, Examples gives a similar sentence and Pinyin the pinyin of the Chinese translation, while Article, Synonyms and Antonyms are for words only. Translation is a seventh family, coloured petrol with a two-speech-bubble icon; the other five stay defined without modules, and a Creative family waits for its first parent. The Notes family (Context, Text) is unchanged. Retires *German explanation*, *German explanation + examples* and *Sentence usage*; the upgrade discards existing decks and pages and keeps sign-in, and the new default deck holds Context and German with all four facets. Partly answers Q40, Q41 and Q43. *Amended 14 October 2026, before implementation:* the facet picker shown when a parent is clicked is dropped; facets work like modules in the window instead
