## Decision

The **Vocabularium Sage** visual identity for 0.6.0: Notion-like *Index Tabs* direction on a greener sage ground, with a *Moss night* dark theme and appearance following the system; six module families colouring each module's index tab, always with its name; Fraunces and Instrument Sans bundled, system serif fonts for CJK; main keys sized by length; page list layouts List (default, grouped by capture date), Table and Gallery, remembered per deck; quiet status (nothing for completed work); generated content rendered from today's text format with a plain-text fallback, storage and API unchanged (C17); capture stays in the context menu and the selection flies into the feedback popup; design-system motion with a reduced-motion fallback ([plan](../../history/plans/visual-identity.md), [design system](https://claude.ai/artifact/6gmEs5nUHAzKCC4do39u9E))
