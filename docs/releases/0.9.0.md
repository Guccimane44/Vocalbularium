# Vocabularium 0.9.0

## Upgrade

Upgrading from 0.8.1 to 0.9.0 keeps every deck and page. Migration `0016` adds the account's interface language, English, so the interface looks as before until another language is chosen under **Account → Language** ([D14](../decisions/d14.md)). Stop the API, back up with `npm run db:backup -- .data/backup-before-0.9.0.dump` (it needs a file it has not written before), run `npm run db:migrate`, start the API with 0.9.0, then replace the extension's files and reload it. The API gains `POST /api/language`, and the account summary a `language` field; a 0.8.1 extension ignores it and keeps working in English with the 0.9.0 API, while a 0.9.0 extension with a 0.8.1 API cannot save a language. Once a language other than English is chosen, the Expertise modules write in it.
