# Vocabularium 0.13.3

## Upgrade

Upgrading from 0.13.2 to 0.13.3 keeps every deck and page; there is no migration. Restart the API with 0.13.3, then replace the extension's files and reload it: the account menu names the account from the `username` the 0.13.3 API adds to the account summary; with an older API it reads Account.
