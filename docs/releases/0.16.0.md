# Vocabularium 0.16.0

## Upgrade

Upgrading from 0.15.0 to 0.16.0 keeps every account, deck, page and clip; there is no migration and the API and extension are unchanged for a user. The German and Chinese generation prompts change, so new and retried cards in those modules are written to the tightened rules. Pronunciation clips that ElevenLabs turns away as busy are asked again after a pause instead of failing, and the server makes at most two speech calls at a time unless `AUDIO_MAX_ACTIVE` says otherwise; a clip still busy says *Too much audio at once*. Restart the API with 0.16.0, then replace the extension's files and reload it.
