# Vocabularium 0.16.6

## Upgrade

Upgrading from 0.16.5 to 0.16.6 keeps every account, deck, page, card and clip, with no migration. Start the API with 0.16.6, then replace the extension's files and reload it. Nothing a user sees changes: the catalog drops four fields that nothing read ([D31](../decisions/d31.md)), and no prompt, stored shape or API payload changes.
