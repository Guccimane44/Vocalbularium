# Vocabularium 0.7.0

## Upgrade

Upgrading from 0.6.3 to 0.7.0 discards every deck and page again, because the earlier data was for testing ([D08](../decisions/d08.md)). Accounts and sign-in stay, and the account starts again with one My Deck holding the main key, Context, and `German` with Article, Examples, Synonyms and Antonyms. Stop the API, back up with `npm run db:backup -- .data/backup-before-0.7.0.dump` (it needs a file it has not written before), run `npm run db:migrate` (migration `0010` adds facet lists and run order; `0011` discards the decks and pages and retires `German explanation`, `German explanation + examples` and `Sentence usage`), start the API with 0.7.0, then reload the extension. Finish or discard pending saves before upgrading: a save for a discarded page fails as deleted. Upgrade the backend and the extension together: a 0.6.3 extension cannot add or render the parent modules, and the 0.7.0 extension needs the 0.7.0 API's facet routes, facet lists and interpretation.
