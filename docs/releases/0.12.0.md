# Vocabularium 0.12.0

## Upgrade

Upgrading from 0.11.0 to 0.12.0 discards every deck and page again, because the earlier data was for testing and development ([D17](../decisions/d17.md), K49). Accounts, sign-in and the language preference stay, and the account starts again with one My Deck holding the main key, Context, and `German` with Article, Examples, Synonyms and Antonyms. Stop the API, back up with `npm run db:backup -- .data/backup-before-0.12.0.dump` (a file it has not written before), run `npm run db:migrate` (migration `0017` discards decks, pages, runs, attempts and receipts and drops the run's stored interpretation), start the API with 0.12.0, then replace the extension's files and reload it: its first start clears cached content, unsent captures and pending saves from earlier builds and keeps sign-in. Finish or discard pending saves before upgrading: a save for a discarded page fails as deleted. Upgrade the backend and the extension together: a 0.11.0 extension expects the run's interpretation, and the 0.12.0 extension needs the cards' own top lines.
