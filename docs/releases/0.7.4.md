# Vocabularium 0.7.4

## Upgrade

Upgrading from 0.7.3 to 0.7.4 discards every deck and page again, because a parent's content changes from markup text to markdown per facet with a structured top line ([D09](../decisions/d09.md)). Accounts and sign-in stay, and the account starts again with one My Deck. Stop the API, back up with `npm run db:backup -- .data/backup-before-0.7.4.dump` (it needs a file it has not written before), run `npm run db:migrate` (migration `0012` discards the decks and pages and starts structured content; `0013` discards them again and stores each parent's core and facets as markdown), start the API with 0.7.4, then reload the extension. Finish or discard pending saves before upgrading: a save for a discarded page fails as deleted. Upgrade the backend and the extension together: a 0.7.3 extension cannot render or edit the 0.7.4 content, and the 0.7.4 extension needs the 0.7.4 API's parent saves.
