# Vocabularium 0.16.1

## Upgrade

Upgrading from 0.16.0 to 0.16.1 keeps every account, deck, page and clip; there is no migration. Restart the API with 0.16.1, then replace the extension's files and reload it: the API gains `POST /api/page/facets/move` ([D26](../decisions/d26.md)), which a 0.16.0 extension never calls, and every card keeps the facet order it had until its owner rearranges it. What a user sees change: the dashboard's subtitle and the sign-in eyebrow are gone, Expertise pages show a word sample only, a second single-instance module reads "Only one {name} module per page.", the page title has a pencil and a ⋯ menu for Delete page, and a card's facets can be dragged into a new order.
