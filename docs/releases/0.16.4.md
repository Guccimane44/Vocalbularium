# Vocabularium 0.16.4

## Upgrade

Upgrading from 0.16.3 to 0.16.4 keeps every account, deck, page and clip; there is no migration and no stored data changes. Restart the API with 0.16.4, then replace the extension's files and reload it: the API accepts a card top line of a new kind, `creativity`, and an Expertise top line with `hasEquation` ([D30](../decisions/d30.md)), which a 0.16.3 extension cannot show. What a user sees change: six new modules in the module window, `English (British)`, `English (American)`, `Chemistry`, and in a new Creativity family `Traditional Haiku`, `Modern Haiku` and `Joke`; German and Chinese offer Etymology, Simple translation and Grammar teacher, which existing cards and decks gain only when the user adds them; and the facet window stops a card or deck parent at 12 facets. To hear the English modules in their own accents, set `ELEVENLABS_VOICES` as the [install guide](../guides/install.md) shows; without it they speak in the default voice.
