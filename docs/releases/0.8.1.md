# Vocabularium 0.8.1

## Upgrade

Upgrading from 0.8.0 to 0.8.1 keeps every deck and page; there is no migration and no API change. Replace the extension's files and reload it; restarting the API only updates its reported version. Facets are now chosen in a parent's facet window, from **Facet** among its actions, instead of the module window ([D13](../decisions/d13.md)).
