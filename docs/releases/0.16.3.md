# Vocabularium 0.16.3

## Upgrade

Upgrading from 0.16.2 to 0.16.3 keeps every account, deck, page and clip; there is no migration and no stored data changes. Restart the API with 0.16.3, then replace the extension's files and reload it: the API accepts a new generation target, `{ scope: "core", componentId }` ([D28](../decisions/d28.md)), which a 0.16.2 extension never sends. An attempt a 0.16.2 API started for a card's Retry may still name the card's earlier core; 0.16.3 ignores it. What a user sees change: a card's Retry, alone or with the page, now reads the key afresh, as a first generation does, instead of keeping the card's reading (D19 amended by D28); the core has a Retry beside its Edit that keeps the reading and writes the meanings again, dimming them in a ring while it runs; a German or Chinese word whose Context selects one of its senses shows that sense first, under "(in diesem Zusammenhang)" or "（在此语境中）", with the word's original meaning always among the meanings ([D29](../decisions/d29.md)). Existing cards show the context meaning only after a Retry.
