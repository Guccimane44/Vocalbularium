# Vocabularium 0.16.7

## Upgrade

Upgrading from 0.16.6 to 0.16.7 keeps every account, deck, page, card and clip, with no migration. Stop the API, start it with 0.16.7, then replace the extension's files and reload it. Start the API before reloading the extension: until both come from the same commit, the account menu says so (below).

What a user sees change:

- **The build's version and commit** are always shown, quietly, at the foot of the homepage and under the sign-in form: *Vocabularium 0.16.7 · 1a2b3c4*. A build made from a checkout with uncommitted changes adds *with uncommitted changes*.
- **Different builds.** When the extension and the API come from different commits, the account menu shows *Different builds: API 1a2b3c4, extension 5d6e7f8* in red under the server. An API older than 0.16.7 shows as `?`. [Install](../guides/install.md#if-something-does-not-work) says what to do.

What changes for the API: every `/health` reply now carries `build`, the API's version, commit and whether its checkout had uncommitted changes (`docs/api/openapi.json`). Packaging refuses an extension built from another commit than the checkout, and the package check refuses one built from another commit than the package's source.
