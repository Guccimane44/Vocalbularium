# Vocabularium 0.15.0

## Upgrade

Upgrading from 0.14.0 to 0.15.0 keeps every account, deck, page and clip; there is no migration and nothing a user sees changes. Restart the API with 0.15.0, then replace the extension's files and reload it. The API's contract now accepts any facet a module declares in the catalog ([D25](../decisions/d25.md)); a 0.14.0 extension keeps working with it.
