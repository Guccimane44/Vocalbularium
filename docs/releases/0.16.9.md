# Vocabularium 0.16.9

## Upgrade

Upgrading from 0.16.8 to 0.16.9 keeps every account, deck, page, card and clip, with no migration. The API's code is unchanged. Stop the API, start it with 0.16.9 so its build matches the extension's, then replace the extension's files and reload it. Until both come from the same commit, the account menu says *Different builds*.

What a user sees change:

- **One menu per module.** A module's tab no longer has a six-dot menu. Clicked, it ejects at most four entries: **Actions**, **Facet**, **About** and **Settings** ([page](../screens/page.md)).
  - **Actions** drops Edit, Retry, Fold and Delete down below it.
  - **Settings** drops placeholder entries marked *Coming soon*: Duplicate, Copy text, Move to page… and Copy to another deck….
  - Only one of the two is open at a time. Escape folds it back, and a second Escape puts the entries away.
  - A failed card still shows its Retry beside the tab.
- **Delete and Retry ask in a panel** beside the entry that asked, with Cancel beside the final button.
- **Deck settings** eject the same entries for each module, with Remove under Actions, and every module has the same space after it, with or without facets ([deck settings](../screens/deck-settings.md)). Folded cards on a page are spaced the same way.
- **Unavailable entries** are grey from the moment they appear, rather than turning grey once they are out.
- **The facet window** opens and closes inside a frame drawn from the card's own top line, and never scrolls. A click on a facet's row opens the facet's page; the row no longer has a **›** ([facet window](../screens/facet-window.md)).

What changes for the owner's tools:

- `npm run test-build` builds a ready-to-load extension from a committed revision, for trying a PR by hand.
- `npm run gate` has GPT-6 Luna audit the judge's verdicts, and the German judge is calibrated on fatal faults ([quality gate](../subsystems/quality-gate.md)).
