# Vocabularium 0.5.0

## Upgrade

Upgrading to 0.5.0 discards every deck and page again, as 0.4.0 did, because the earlier data was for testing ([D02](../decisions/d02.md)). Accounts and sign-in stay, and the account starts again with one fresh My Deck holding the main key, Context, and `German explanation + examples` modules. On the way, migration `0006` retires `<The selected>` and `<The selected + original language tag>` ([D03](../decisions/d03.md)): it removes their instances and components, which matters only for a database that stops at `0006`. Migration `0008` then discards decks and pages. Upgrade the backend and the extension together: the 0.5.0 extension's first start clears cached content, unsent captures and pending saves from earlier builds and keeps sign-in, and older extensions do not work with the 0.5.0 backend.
