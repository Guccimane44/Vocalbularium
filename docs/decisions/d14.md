- **Opened:** 2026-10-22
- **Status:** implemented (0.9.0)
- **Notion:** [Accepted 2026-10-22](https://app.notion.com/p/401bb135020881fc9109db55cdb88e68)
- **Source:** Owner direction in chat, 22 October 2026
- **Affected docs:** [shared-ui](../subsystems/interface.md) (interface language and the preference), [scope](../product/scope.md) (localisation, accepted for 1.0), [modules](../subsystems/module-catalog.md#catalog) (the Expertise modules' language refers to the preference), Q69 (the owner's answer, 8 October 2026; temporary position)
- **Open items:** K10, K35–K38 resolved

## Decision

**English first, localised for 1.0.** Every interface text in Vocabularium is English, and during development English is the default **language preference**. The interface will be localised into the major languages, which the user chooses as a preference, and 1.0 ships with them; English stays the default. The interface language is independent of the language of generated content, which stays multilingual by module (Q69, the owner's answer of 8 October 2026). Recorded now so that new interface text, D13's explanations and the Expertise modules' English ([modules](../subsystems/module-catalog.md#catalog)) are understood as the English default, not a permanent choice; the languages, the preference and the string process are planned in a later release before 1.0. Answers Q69's open point (K10): English-only is a development position, not the 1.0 one
